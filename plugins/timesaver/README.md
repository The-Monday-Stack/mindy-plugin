Install `timesaver` from `The-Monday-Stack/mindy-plugin`, in the `mindy` marketplace. In Claude Code, type `/plugin marketplace add The-Monday-Stack/mindy-plugin`, then `/plugin install timesaver@mindy`. In the ChatGPT app or Codex, add `The-Monday-Stack/mindy-plugin` in Plugins and install `timesaver` from `mindy`. Then type `/timesaver` with your Mindy TimeSaver access code.

Mindy TimeSaver keeps your sessions in Claude Code and Codex. Start with your Mindy TimeSaver access code.

To load the context you need, start a session with /mindyload and then what you want to work on or think about. When you finish, type /mindyend to save the session to your Mindy TimeSaver (MTS). Nothing from the session is saved until you do. Each day, when you start a session, your MTS compresses the previous day's sessions into a summary. This also happens every week for days, every month for weeks, quarter for months and year for quarters. Use /timesaver-off and /timesaver-on to turn saving off or on.

Don't forget - nothing at all will be saved to Mindy TimeSaver unless you type /mindyend at the end of a session!
