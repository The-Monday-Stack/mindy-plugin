MINDY TimeSaver keeps what you asked, decided and did, so you can pick up earlier work with your AI.

Add MINDY TimeSaver Setup from mindy-plugin. Type /install-mts with your access code to set up your saves folder on this Mac. Add MINDY TimeSaver from the same marketplace when setup asks.

Start with /mindyload and what you want to work on. Type /mindyend when you finish to save the session. Use /mindysearch to find saved work, /mindyhelp for a reminder, and /timesaver-remove to remove MINDY TimeSaver.
